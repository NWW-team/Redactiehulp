Beveiligde versie: de regelset staat in Supabase en is alleen te lezen door vooraf toegestane accounts.

Wat deze pagina wel en niet beschermt. Deze pagina is publiek: hij staat op GitHub Pages, en wie de URL heeft kan hem openen en de JavaScript lezen. Dat hoort zo — er staat geen geheim in. De bescherming zit in de RLS-policies in Supabase: die staan vóór de gegevens en bepalen wie de regelset mag lezen. Zonder een toegestaan account komt er niets terug, langs welke weg je het ook probeert. Het inlogformulier hieronder is de bediening daarvan, niet de beveiliging zelf. Mag ook de pagina zelf niet te openen zijn, dan is daar een extra laag vóór de bestanden voor nodig (bijvoorbeeld Cloudflare Access) — GitHub Pages kan dat niet. De regelset in dit project is fictief, niet de officiële NWW-schrijfwijzer.

Inloggen

Toegang is beperkt tot vooraf aangemaakte accounts. Er is geen registratie: aanmelden kan alleen als een beheerder je account heeft aangemaakt én op de toegangslijst heeft gezet.

Geen toegang

Je bent ingelogd, maar dit account staat niet op de toegangslijst. De database geeft daarom geen regelset vrij. Vraag een beheerder om je account toe te voegen.
